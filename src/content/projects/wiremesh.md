WireMesh explores online stores as a peer-to-peer protocol instead of only a centralized platform.

The project combines a Go backend, protocol layer, P2P networking, and a React UI that can be embedded into a single deployable binary.

## Why it exists

I wanted to see what a small, self-contained marketplace system could look like if the protocol and deployment story were treated as part of the product.

## Shape

The practical goal is boring in a good way: run one binary, open the local UI, and have the store/admin/setup surface available without a pile of moving parts.
